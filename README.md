# 🌍 ECOWATCH AI - Environmental Monitoring System

AI-Powered Environmental Monitoring System for Sustainable Ecosystem Management

## 🚀 Live Deployment

**Frontend**: [https://environment-ruby.vercel.app](https://environment-ruby.vercel.app)
**Backend API**: [https://environment-enx2.onrender.com](https://environment-enx2.onrender.com)
**API Documentation**: [https://environment-enx2.onrender.com/api/docs](https://environment-enx2.onrender.com/api/docs)

## ✨ Features

- **Real-time Dashboard**: Live environmental metrics and analytics
- **AI Copilot**: Intelligent environmental assistant powered by AI
- **Image Analysis**: Upload and analyze environmental images
- **Carbon Calculator**: Track and calculate carbon footprint
- **City Rankings**: Compare environmental health across cities
- **Predictive Analytics**: ML-powered environmental forecasts
- **News & Alerts**: Stay updated with environmental news
- **Sustainability Tips**: Personalized recommendations

## 🛠️ Tech Stack

### Frontend
- React 19
- Vite
- TailwindCSS
- Redux Toolkit
- Recharts
- React Router
- Leaflet (Maps)

### Backend
- FastAPI
- Python 3.11
- Scikit-learn
- XGBoost
- Pandas
- NumPy

## 📦 Installation

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## 🔗 API Endpoints

- `/api/dashboard/metrics` - Get environmental metrics
- `/api/copilot/chat` - AI assistant chat
- `/api/image/analyze` - Image analysis
- `/api/predictions/forecast` - Environmental predictions
- `/api/carbon/calculate` - Carbon footprint calculation
- `/api/cities/rankings` - City environmental rankings
